# StudentManagementSystem
A Java-based student management system using OOP.

A Java-based Student Management System developed as a portfolio project.

## Description

This application allows users to manage students, courses, and student enrollments through a simple console-based menu.

The project was developed to practice object-oriented programming, Java collections, CRUD operations, and basic software structure.

## Features

- Add, display, update, and delete students
- Add, display, update, and delete courses
- Enroll students in courses
- Display courses enrolled by a student
- Prevent duplicate students and courses
- Console-based menu
- Input validation

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Eclipse IDE

## Project Structure

- `Student` – represents a student
- `Course` – represents a course
- `StudentService` – manages student operations
- `CourseService` – manages course operations
- `Enrollement` – represents a student enrollment
- `EnrollementService` – manages enrollments
- `Main` – contains the main program and menu

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or another Java IDE.
3. Run the `Main` class.
4. Follow the instructions displayed in the console.

## Example

The application allows a user to create a student such as:

- ID: 1
- Name: Alice
- Age: 22
- Email: alice@gmail.com

A course can then be created and assigned to the student.
